# 外观工坊（ui-studio）

Hermes 桌面应用的外观插件：配色、字号/疏密/圆角/气泡宽度/头像大小、侧栏与档案栏观感、头像状态动画、窗口材质、宠物层级，全部收在「设置 › 外观」一个面板里。

插件是单个 `plugin.js`（约 375 KB，纯 ESM，无构建步骤、无外部资源，内联 15 张 base64 图）。

## 安装

**方式一（复制文件，最快）**

1. 在本机建目录：`~/.hermes/desktop-plugins/ui-studio/`
2. 把 `plugin.js` 放进去
3. 应用内按 `⌘K` → **Reload desktop plugins**（或重启应用）

**方式二（从 Git 仓库装，能升级）**

```bash
hermes plugins install https://github.com/<你的用户名>/ui-studio
```

仓库根目录放 `plugin.js` 即可——这是「只有桌面端」的插件，不需要 `plugin.yaml`。
仓库名必须是 `ui-studio`，因为插件的 id 是 `ui-studio`，安装时文件夹名要与它一致。

**方式三（应用内）**

Capabilities → Plugins → 用 Git 地址安装，安装后在列表里打开开关。

## 使用

应用内打开 **设置 › 外观**：顶部是配色（薄荷 / 天空 / 丁香）与预设，下面按板块给档位（疏密、字号、圆角、气泡最大宽度、头像大小），再往下是头像动画、窗口材质、宠物层级等开关。所有改动即时生效、自动保存；底部可一键恢复默认，或关掉总开关回到应用原样。

## 兼容性

样式是按 Hermes 桌面应用当前的 `data-slot` 结构与设计变量写的。应用大版本升级若改动这些结构，个别板块可能失效；总开关关掉即可完全还原，不会残留。
